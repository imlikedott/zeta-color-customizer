## 📥 설치 방법

### 1\. 템퍼몽키 설치

브라우저에 **Tampermonkey(템퍼몽키)** 확장 프로그램 설치

* 크롬 · 엣지 · 웨일: 확장 프로그램 스토어에서 "Tampermonkey" 검색
* 파이어폭스: 부가 기능에서 "Tampermonkey" 검색

### 2\. 유저스크립트 허용 켜기 (크롬 계열만)

요즘 크롬은 템퍼몽키 깔아도 이거 안 켜면 스크립트가 안 돌아감 (제일 많이 놓치는 부분)

1. 주소창에 `chrome://extensions` 입력 (엣지는 `edge://extensions`)
2. Tampermonkey **세부정보** 누르기
3. **사용자 스크립트 허용** 켜기

> 옛날 버전 크롬은 이 스위치가 없음 → 확장 프로그램 페이지 오른쪽 위 \\\*\\\*개발자 모드\\\*\\\* 켜면 됨

### 3\. 스크립트 설치

아래 링크 누르면 템퍼몽키 설치 화면 뜸 → **설치** 누르면 끝

👉 [**설치하기**](https://github.com/imlikedott/zeta-color-customizer/raw/refs/heads/main/zeta-color-customizer.user.js)

### 4\. 사용 시작

제타 들어가면 화면 구석에 🎨 아이콘 생김 → 누르면 설정창 열림
안 생기면 2번 허용 켰는지 다시 확인하고 제타 새로고침

## 🔒 개인정보

* 설정 · 메모 · 저장 슬롯 전부 **내 브라우저 안에만** 저장됨, 어디로도 안 보냄
* 로그인 정보나 대화 내용 읽어서 보내는 기능 없음. 화면 읽는 건 색 칠할 위치 찾으려고 보는 거임
* 밖에서 받아오는 건 **🔍 CSS 변수 검색** 처음 실행 할 때 자동으로 검색하고, 직접 눌렀을 때 제타 자기 디자인 파일(CSS) 읽는 거 하나뿐 이 역시 개인 설정 안에서만 유효
* 접속 허용 주소는 제타(zeta-ai.io) · 구글 폰트 · jsdelivr 로만 제한해 둠
